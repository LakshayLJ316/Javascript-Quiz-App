
# QuizMaster - JavaScript Quiz Application

## About the Project

QuizMaster is an interactive multiple-choice quiz application
developed using HTML, CSS, and JavaScript.

The application allows users to test their general knowledge
through a series of 10 questions and receive instant feedback.

## Features

- 10 multiple-choice questions
- Dynamic question display
- Instant answer feedback
- Correct and incorrect answer highlighting
- Automatic score calculation
- Next and Previous navigation
- Progress bar
- Final score and percentage
- Answer review section
- Restart quiz functionality
- Dark and Light mode
- Best score saved using Local Storage
- Keyboard shortcuts
- Responsive design for mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Click Start Quiz to begin.
